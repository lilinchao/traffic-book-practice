# 第8章：夜间步行街的分方向行人通行调查

## 研究问题

夜间街道调查常受遮挡、强光、静止人群与身份断裂影响。检测框较多或两组总人数相同，是否就足以支持通行量统计？本实验将检测、身份关联、逐事件匹配和分方向计数分开核查，判断误差如何传递到步行交通调查。

本课使用MOT17-04真实夜间街道序列，不将其臆称为天津路口或某个已经实施治理的工程。它与SinD地面轨迹实验互补，不能混用位置单位、ID或评价分母。

## 固定影像协议

协议`ch08-night-pedestrian-v1`预先固定整段1-1050帧，不挑最好看的片段。使用外部COCO预训练YOLOX，不在本序列训练；这是公开训练序列上的教学复核，不是独立场景泛化成绩。

1. **检测**：每3帧执行一次，共350帧；RGB输入、640×640左上角letterbox填充114；按官方实现解码并作IoU=0.5的NMS。比较置信度0.35与0.60，保留两组，不事后只报道较好一组。
2. **跟踪**：取预测框底边中心作为图像观测点，10像素为一个计算单位。常速度卡尔曼滤波加带门限匈牙利分配；门限45像素，失配保留0.5秒。源ID不输入模型；没有外观重识别，不能称为完整DeepSORT或SORT复现。
3. **事件**：画面y=300像素为线，死区±5像素，间断上限0.5秒；每个新ID每方向最多一次。方向仅为画面向上/下，不赋予未经测量的地理方向。参考事件由提供方人工框及ID按原30Hz、同线和同死区导出；模型事件按10Hz提取。
4. **检测评价**：只评价mark=1、class=1的人工目标框；与预测框按IoU≥0.5一对一匹配。未匹配预测若与人物干扰类别2/7/8/12的框IoU≥0.5则忽略。报告TP、FP、FN及查准率/查全率，不命名为mAP。
5. **身份核查**：统计同一人工ID在0.5秒内相邻成功匹配时是否换了新ID。它不是官方IDF1、HOTA或完整MOTA。
6. **事件评价**：模型事件必须在发生帧有独立框匹配身份，与参考事件身份和方向一致且时间差≤0.5秒，一对一匹配后报告事件TP/FP/FN。未匹配和身份不明事件不强行判为正确；不以两组总数接近替代逐事件准确性。

模型推理的输入是原视频；关联输入是预测位置；人工标注只在评价和网页叠加时读取。事件参考是“人工框/ID导出的参考事件”，不是教师另行完成的独立逐人计数。标注本身也可能有误差，需结合视频核查。

## 运行与交付

```bash
python -m pip install -r chapters/python/video-requirements.txt
python chapters/python/prepare_video_lesson.py

```

也可在第8章同一个工作本的影像部分逐格执行。主网页展示已实际计算并冻结的结果，学生在工作本中重新推理和修改代码；不能把切换展示阈值描述为网页重新训练。

结果写入`outputs/ch08-video/`：`results.json`保留逐框、身份、匹配与事件，`metrics.csv`汇总两组评价，`events.csv`列出两类事件，`review.csv`列出待回看片段。网页核查表支持记录当前视频时刻、方向和观察依据，再导出个人核查JSON；记录不自动升级为官方真值。

随作业提交：实际运行结果、参数与输入哈希、至少一处漏检/错接/事件不匹配的画面依据、分方向调查表和适用性报告。该影像结果与SinD的`ch08_primary.json`**分别保留**；主JSON自测不会代验影像成果。

## 工程分析

先检查误差集中在强光、遮挡、远处小目标还是线附近的身份变化，再讨论提高阈值对漏检和误检的影响。即使检测指标改善，逐事件结果仍可能变差，需同时引用两个阶段的证据。对无法匹配的具体事件说明“未确认”，不要补造人工结论。

画面线没有对应的实地宽度、道路断面或地理坐标，无法报告人/米、米/秒、通行能力或小时设计流量。35秒片段的分方向通过事件只用于验证调查方法；真实工程还需要断面布置、地面标定、更长调查时段、可见性审查以及现场复核。
