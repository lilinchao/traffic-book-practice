## 真正可运行的代码

### SQL

- 固定sql.js **1.14.2**，采用`sql-asm-memory-growth.js`单文件构建。原引擎的UTF-8内容被包装为JS字符串，随后在本机Worker加载，没有修改SQLite算法。官方源码、归档和引擎哈希见`vendor/manifest.json`，原MIT许可见`vendor/SQLJS-LICENSE.txt`。
- `raw_weather`保留原始九列，增加`row_id`；`hourly(station_id,local_time,traffic_volume,weather_rows)`包含通过冲突核查的唯一小时；`station`的站点ID、道路和方向来自UCI元数据，是课堂补充字段。
- 每次运行重新从固定数据库快照建立副本；写操作只作用于该次副本。代码可以编辑，不是预生成答案。结果由SQLite求值。
- 每次最多8条语句，每条预览最多200行，长文本最多4,096字符。显示“200+”只表示预览截断，不表示总行数。请使用COUNT或筛选查询核查完整规模。
- 工作线程运行限时20秒，支持停止；环境首次建表限时60秒。切换教学页会停止尚未完成的运行。
- SQLite日期函数与其他数据库方言不完全相同；本课使用原始本地标签，不恢复夏令时或时区偏移。

### Python

- 使用固定Pyodide 0.29.3，是针对浏览器环境的兼容性选择，不宣称其为最新版本。每次执行重新注入真实`records`和`columns`，示例据此建立DataFrame，不共享上次示例的数据表。
- 实际执行NumPy、Pandas计算，显示stdout、错误和实际依赖版本。不是JavaScript猜测Python语句，也不把预计算结果冒充执行结果。
- 文本输出最多60,000字符；实验记录中最多保存其前10,000字符。复杂、超时或无限循环可停止并重建Worker。Python包加载最长180秒，代码运行最长20秒。
- 原始数据与默认实验代码不发送到计算服务器。加载运行时涉及第三方CDN请求；自行编写的网络访问代码仍受浏览器网络规则约束。不要粘贴密钥、个人资料或不信任的网络代码。
- 下载的Python示例包含本地CSV读取前导代码；把它放在解压课堂目录中即可找到`data/ch02_raw.csv`。下载的SQL需在具有上述表结构的SQLite环境运行，最方便的方式是贴回本课堂SQL编辑器。

## 数据、处理和边界

### 道路监测主线

[John Hogue (2019), Metro Interstate Traffic Volume](https://archive.ics.uci.edu/dataset/492/metro+interstate+traffic+volume)，UCI，DOI:10.24432/C5X60B，CC BY 4.0。来自MnDOT ATR 301的I-94西向小时交通量，原始CSV及完整天气字段沿用主课程快照。

- 原始48,204行，40,575个不同本地小时标签，7,629条重复附加行；同小时交通量冲突数为0。
- “重复附加行”不是“有重复的小时数”；天气主标签集合也不等于完整天气行。课堂保留原始CSV，不丢弃详细描述。
- 2017年8,760个应有标签、8,713个观测小时、47个缺口。07、08、09时完整的日期358个；7个日期不完整（6日部分缺测、1日三小时全缺），与`ch03-bootstrap-v1`一致。
- 原始行没有空单元格，不能据此宣称时间序列没有缺口。`holiday`的字符串`None`保持类别含义，不当作Pandas缺失值。
- 年度审计默认使用该年首末观测之间的小时骨架；可切换完整日历年。缺口不是已查明的设备故障，年度覆盖起止必须一起说明。
- 保留原始本地标签。代码使用UTC日期函数作为不受浏览器时区影响的标签运算轴，不是把原时刻转换成UTC，也不重建夏令时。主键设计在多站点、多方向和具有偏移信息的真实系统中必须扩展。
- 唯一小时的交通量可保留一个一致值，但不能把原始行加权统计误认为等小时统计。缺口不填0。已记录零值单独标识，需要进一步核查。
- temp由K转换为°C；−60至60°C仅作课堂演示筛查阈值，不是设备验收标准。
- 人为+100辆冲突只在实验副本中演示失败检查，绝不进入真实数据、小时导出或后续项目。

### 空间扩展

[NYC Open Data Motor Vehicle Collisions](https://data.cityofnewyork.us/Public-Safety/Motor-Vehicle-Collisions-Crashes/h9gi-nx95)，2024年1月7,542条事故记录，沿用第五章固定7,068个有效坐标，474条未补位置；遵守NYC原始条款。展示的是经纬度散点，不含路网底图或暴露量，不报告风险或事故识别精度。

### 轨迹扩展

[SOTIF-AVLab/SinD](https://github.com/SOTIF-AVLab/SinD)，固定提交`930e4dea78d924c6e9a58ff8e378331f93bba8ec`，天津`8_2_1`平滑车辆轨迹。沿用第八章120秒、11,531点、77源ID快照，本课堂只展示按源ID升序取出的3条轨迹（1、2、3），共1,325点。毫秒转换为秒，地面xy为米。

这是提供方平滑轨迹，不是本课视觉模型输出。源ID用于展示，未运行关联算法；不得宣称检测或计数准确率。相邻记录交换明确标为错误对照，不改变真实坐标。数据遵守自定义非商业许可，原文`data/SIND-LICENSE.txt`，不是CC0或课程MIT许可。

上述三种资料来自不同道路、城市和时期，**不合并为一个交通总体**。
